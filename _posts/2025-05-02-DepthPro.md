# DepthPro (single image depth)

# **프로젝트 개요**

| **항목** | **내용** |
| --- | --- |
| **프로젝트명** | DepthPro 단일 이미지 깊이 추정 및 포인트클라우드 비교 실습 |
| **모델(Model)** | DepthPro (Apple) |
| **데이터셋(Dataset)** | 사용자 보유 이미지 3장 (도시 버드아이뷰 / 테슬라 사이버트럭 / 실내 거실) |
| **환경** | Windows, RTX 3060, PyTorch, CUDA 13.1 |

---

# **목적 (Objective)**

### **▪ 실험의 목표**

- 단일 이미지 기반 DepthPro가 장면 유형에 따라 깊이 품질이 어떻게 달라지는지 확인
- depth map과 point cloud 품질 비교 및 시각적 문제 원인 파악

### **▪ 얻고자 하는 인사이트**

- 하늘/평탄 영역에서 depth 품질 저하 원인
- 반사/밝은 영역에서 경계 흐림 현상 파악

---

### **▪ 실험 동기**

- DepthPro의 monocular depth 추정 품질을 실제 장면에서 확인
- 다양한 장면(도시/도로/실내)에서 포인트클라우드가 어떻게 생성되는지 비교

### **▪ 참고 모델 핵심 아이디어**

- 단일 이미지로부터 depth를 추정하고, focal length를 함께 추정하여 metric depth 복원

---

# **📦 데이터셋 (Datasets)**

| **구분** | **내용** |
| --- | --- |
| **데이터셋 이름** | 웹 수집 이미지 3장 |
| **크기** | 3 images |

| **평가 지표** | 정량 지표 없음 (정성 평가) |

# **🧠 실험 설계 (Experiment Design)**

### **▪ 깊이 통계 결과**

- **City 이미지**: min=1.5026, max=8.0376, mean(depth>0)=1.0
- **Tesla 이미지**: min=3.4858, max=10000.0, mean(depth>0)=1.0
- **Indoor(거실) 이미지**: min=1.7734, max=8.28743, mean(depth>0)=1.0

### **▪ 주요 관찰**

- **City**: depth map 및 point cloud 모두 준수하게 출력
- **Tesla**: 하늘 영역과 트럭 천장 경계가 섞여 흐릿하게 보임
- **Indoor(거실)**: 쇼파/의자/액자/커튼 등 가구가 모두 잘 표현됨

### **▪ 해석**

- 구조적 단서가 풍부한 장면(도시, 실내)은 안정적인 깊이 추정
- 하늘/반사 영역이 포함된 장면은 경계 혼합과 depth 퍼짐 발생

---

# **인사이트 및 결론 (Insights & Conclusion)**

- DepthPro는 구조물이 명확한 장면에서 안정적으로 깊이 추정
- 하늘/반사 영역에서는 경계가 붕괴되어 포인트클라우드 품질이 저하됨

> “DepthPro는 구조적 단서가 많은 장면에서 안정적이나, 하늘·반사 영역에서는 경계 혼합이 두드러졌다.”
